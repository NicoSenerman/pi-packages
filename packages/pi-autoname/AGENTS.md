# pi-autoname — Agent 规范

## 文件职责与阅读顺序

- 本文件只记录会话命名扩展长期工程与隐私边界；触发时机、配置和安装以 `README.md`、源码和测试为准。
- 修改前读取 `README.md`、`package.json`、目标实现和测试，不把当前时间间隔或功能清单复制为规范。

## 项目边界

- 命名必须来自会话语义并保持简短稳定，不使用未经处理的模型裸回答，也不改写用户显式设置的名称语义。
- 会话内容和生成标题属于隐私数据；不写日志、不发送到未授权 provider、不持久化额外 prompt。
- 模型与凭据使用 Pi 当前公开配置，不硬编码 provider、模型或 Key。
- 自动与手动触发共享同一命名核心，避免两套行为；并发或重复触发必须有去重与失败降级。
- 调试默认关闭；先用测试建立可重复信号，连续两次同类失败且范围未缩小时停止原路径。

## 验证

```bash
npm test
```

触发或 Pi API 变化还需临时加载当前仓库，验证自动命名、`/autoname`、reload 后状态和模型失败降级；未做真实模型测试时明确说明。

## 文档与 Git

- 触发语义、配置、隐私边界或安装入口变化时同步 `README.md` 与用户可感知的 CHANGELOG 条目。
- 未经用户明确要求，不执行 commit、push、tag 或 npm publish。
